# Lastro

Registro das interações externas que o projeto recebe: contatos de outros órgãos, pesquisadores,
fornecedores e contribuidores; relatos de uso e de fracasso; comparações de hardware. É a
evidência de que o problema descrito no README é compartilhado — e o material que a próxima
conversa reaproveita.

Cada interação é uma pasta `AAAA-MM-<origem>/` com um `registro.md` no mesmo formato
(quem, quando, demanda, o que enviamos, autorização, o que voltou) e os arquivos produzidos
para aquela conversa (deck, documento explicativo, comparativo). O que **enviamos** do próprio
repositório — README, spec, aplicativo — não é copiado: o registro aponta a tag ou o commit
exato, que é o lastro de "o que a pessoa recebeu".

## Regra de privacidade

Este diretório é público e está sob CC BY 4.0, como o resto de `docs/`. Portanto:

- O registro traz **nome, instituição e função** da pessoa só depois de autorização expressa,
  pedida na primeira resposta. Até lá, a interação é descrita pela instituição e pelo papel.
- **Nunca** entram aqui telefone, e-mail, mensagens originais (a autoria é da outra pessoa) ou
  qualquer documento que ela tenha enviado sem pedir publicação. Esse material fica em
  `docs/interno/`, que o git ignora.
- Registrar "o que voltou" (relato, dado, crítica) também depende de autorização, ou é feito de
  forma agregada e sem atribuição.
